## 2026 Fall BMI530 Lab

This lab contains a small number-guessing game and beginner-friendly pytest tests.

### Play the game

```bash
python app.py
```

### Install pytest

```bash
python -m pip install pytest
```

### Run the tests

```bash
python -m pytest -q
```

The tests show three useful pytest ideas: plain assertions, parameterized tests,
and checking expected exceptions with `pytest.raises`.
